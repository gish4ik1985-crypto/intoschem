# Into Schem — веб-сборка

Симулятор электрических цепей: шестнадцать реальных приборов, каждый со своей
неисправностью, и один уровень свободной сборки, где схему собирает сам игрок.
Под игрой честный решатель (MNA + метод Ньютона для нелинейных компонентов) —
ничего не подыгрывает.

## Запуск

```
python web/_dev_server.py
```

и открыть <http://127.0.0.1:8791/>.

Сервер нужен только затем, чтобы браузер не кэшировал правки и чтобы работал
снимок экрана для разработки. Игре он не требуется: `index.html` открывается и
напрямую, но в этом случае браузер может запретить сохранение прогресса.

## Что где

| Путь | Что там |
| --- | --- |
| `js/circuit.js` | Решатель. Точный порт `core/*.gd` из Godot-сборки — числа обязаны совпадать |
| `js/engine/util.js` | Числа, вектора, цвет, формат величин («4,7 кОм», «18,9 мА») |
| `js/engine/palette.js` | Единственный источник цвета: шкала потенциала и шкала накала металла |
| `js/engine/draw.js` | Примитивы: свет, металл, дорожки с бегущим зарядом |
| `js/engine/parts.js` | Как выглядит каждая деталь. Правило: узнаётся по силуэту, подпись — подтверждение |
| `js/engine/board.js` | Плата и фон сцены |
| `js/engine/devices.js` | Приборы поверх голого решателя: светодиод с порогом, лампа, мотор, реле |
| `js/engine/hud.js` | Интерфейс: карточка уровня, приборы, полоса цели, выбор номинала |
| `js/engine/level.js` | Каркас уровня: симуляция, нагрев, удержание цели, мышь |
| `js/levels/` | Сами уровни. Порядок объявления в `index.html` = порядок прохождения |
| `js/scenes/` | Меню, карта, кодекс |

## Как добавить уровень

Уровень — один объект-описание. Обязательное: `id`, `index`, `title`,
`teaches`, `brief`, `lesson`, `hints`, `parts`, `wires`, `build`, `apply`,
`read`, `status`, `goal`, `score`, `meter`, `map`.

Каркас берёт на себя всё остальное: решение цепи каждый кадр, нагрев и сгорание
деталей, удержание условия победы, сохранение того, что игрок накрутил,
всплывающий выбор номинала, подсказку под курсором и самописец.

Перед тем как считать уровень готовым — прогнать его решателем и убедиться, что
задуманное решение действительно даёт задуманные числа. Расчёт «на бумаге»
регулярно расходится с решателем на десятки процентов.

### Уровень свободной сборки (`spec.freeform`)

Уровень 17 «Верстак» устроен иначе: вместо фиксированных `parts`/`wires`/`build`/
`apply` он задаёт `freeform: true` и `sandbox: { palette, make(kind), add(circuit,
a, b, part) }` — `js/levels/l17_workbench.js`. Игрок сам ставит детали из палитры
и сам тянет провода между их выводами; каркас (`js/engine/level.js`) строит цепь
заново из этого графа при каждом структурном изменении, а не из готового
`build()`. Такой режим предполагается один — это не общий паттерн для новых
уровней, а отдельная механика, которую специально проверяли отдельно.

## Инструмент проверки картинки

Скриншот окна в рабочем окружении не снимается. Вместо него страница
фотографирует себя сама:

```js
// в консоли страницы
await import('/_dev_snap.js');  // или подключить тегом script
await window.__snap('имя');     // PNG ляжет в web/_snap/имя.png
```

Снимок склеивает канву и слой интерфейса (через SVG `foreignObject` со
встроенным CSS), так что видно ровно то, что видит игрок.
